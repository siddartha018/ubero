# Ubero 🚗💨

**Ubero** is a full-stack, end-to-end ride-sharing web application inspired by Uber. Built with JavaScript across both frontend and backend, it manages the complete ride lifecycle—from user registration and profile management to booking rides and driver-passenger routing.

---

## ✨ Key Features

- **👤 User & Profile Management**: Complete user onboarding, authentication, and user profile management endpoints.
- **🗺️ Interactive Mapping & Location**: Real-time pickup/drop-off location selection and route visualization.
- **🚕 Ride Request & Dispatch**: Automated driver-passenger matching workflows and ride status updates.
- **📱 Responsive UI**: Clean, intuitive web interface designed for both mobile web and desktop users.
- **⚙️ Modular Monorepo Architecture**: Cleanly separated `/frontend` and `/backend` codebase structure.

---

## 🛠️ Tech Stack

- **Language:** JavaScript (Node.js)
- **Frontend:** HTML5, CSS3, Modern JavaScript Framework / DOM handling
- **Backend:** Node.js, Express.js REST APIs
- **Database:** MongoDB / PostgreSQL
